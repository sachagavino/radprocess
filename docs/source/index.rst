Radprocess documentation
========================

Radprocess is a Python package for post-processing RAMSES MHD simulations
with RADMC-3D and POLARIS, producing synthetic dust continuum observations.
It was originally created to use RAMSES multi-fluid simulations and to generate polarization maps.
